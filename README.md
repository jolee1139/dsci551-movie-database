
# DSCI 551 Movie Database Project

A relational database project combining MovieLens 20M user-rating data with movie metadata from the TMDB API.

## Project goals

- Build a reproducible data-acquisition and transformation pipeline
- Implement a relational database in MySQL
- Develop meaningful movie-rating queries
- Compare alternative indexes and execution plans
- Demonstrate the database through a Streamlit application

## Data sources

- MovieLens 20M
- TMDB API

## Project structure

- `src/` — data acquisition and transformation scripts
- `sql/` — schema, loading, and query scripts
- `app/` — Streamlit application
- `experiments/` — query plans and performance results
- `data/` — local data files excluded from Git
